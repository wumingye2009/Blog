Creating a Bar Chart Race with Python

Recently I came across some amazing videos online using bar chart race to show data dynamically. Inspired by that, I decided to handcraft my own bar chart race using CO₂ emissions data. Later, I added some background music in Adobe Audition to make it more engaging. In this blog, I’ll share with you how I built it step by step.

What is a Bar Chart Race?

A bar chart race is a dynamic visualization that shows how values change over time across categories. Bars move, grow, or shrink with each frame, creating an intuitive way to track trends and rankings. It’s especially popular for historical datasets like GDP, population, or in this case — CO₂ emissions.

Step 5: Rendering the Bar Chart Race

Finally, we generate the animation using the bar_chart_race library:

  • n_bars=10 → show top 10 countries
  • steps_per_period=10 → smooth transitions
  • period_length=500 → each frame lasts 500 ms
  • period_label=True + period_fmt → show year as Year:2023
  • tick_label_size → control country name font size
  • bar_size → adjust bar thickness

The output is an MP4 file that you can play or edit further.

🎬 The Result

Once rendered, you’ll get an MP4 animation. I then used Adobe Audition to add background music. The result is a dynamic and engaging visualization that tells the story of CO₂ emissions over time.

Final Thoughts

Creating a bar chart race is fun and highly effective for storytelling with data. With just a few lines of Python code, you can turn raw CSV files into stunning dynamic videos. Add some background music, and you have content that’s both informative and entertaining.

So go ahead, try it with your own dataset — GDP, population, or anything else you find interesting!
