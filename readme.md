# MyBlog

A personal blog powered by [Hexo](https://hexo.io/) and the [Butterfly theme](https://github.com/jerryc127/hexo-theme-butterfly).

## 🌟 Features
- Static blog generated by Hexo
- Beautiful [Butterfly theme](https://github.com/jerryc127/hexo-theme-butterfly) with rich customization
- Support for tags, categories, archives, and search
- Easy deployment to GitHub Pages

## 📂 Project Structure
Myblog/
├── _config.yml # Hexo main config
├── _config.butterfly.yml # Butterfly theme config (copied from theme and customized)
├── package.json # Node.js dependencies
├── source/ # Blog content (markdown posts, images, etc.)
│ ├── _posts/ # Markdown posts
│ ├── img/ # Site-wide images (e.g. favicon, logo)
│ └── ...
├── themes/
│ └── butterfly/ # Butterfly theme (added as a git submodule)
└── public/ # Generated static files (auto-created by Hexo)
